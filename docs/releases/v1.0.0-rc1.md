# RemoteX Android v1.0.0-rc1

Release candidate pertama RemoteX Android, client remote administration mobile-first untuk Linux.

## Fitur utama
- Desktop melalui VNC/RFB.
- Terminal melalui SSH.
- File melalui SFTP.
- Trackpad mobile, klik kanan dua jari, scroll, clipboard, screenshot, special keys, fullscreen, dan rotate.
- Mode kualitas VNC Otomatis, Performa, Seimbang, dan Tinggi.
- Suara sistem Linux melalui SSH.
- Mode Menonton H.264 + AAC melalui SSH untuk playback video/audio yang lebih halus dan sinkron.
- Kredensial tersimpan dienkripsi menggunakan Android Keystore.
- Profile export/import tanpa kredensial.

## Host Linux untuk fitur lengkap
Ubuntu/Debian:

```bash
sudo apt install openssh-server x11vnc pulseaudio-utils ffmpeg x11-utils
```

Baca `docs/PANDUAN_PENGGUNAAN.md` untuk setup dan penggunaan lengkap.

## Catatan RC
Mode Menonton dan hardening mode kualitas Tinggi masih relatif baru dibanding Desktop/SSH/SFTP. Jika menemukan crash, sertakan langkah reproduksi dan logcat yang sudah dibersihkan dari data sensitif.

## Keamanan
VNC klasik tidak menyediakan enkripsi sesi. Gunakan VNC pada LAN atau VPN tepercaya dan jangan membuka port VNC langsung ke Internet.
