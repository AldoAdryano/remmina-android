# RemoteX Android v1.0.0-rc1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare RemoteX Android for a safe, documented `v1.0.0-rc1` GitHub release.

**Architecture:** Runtime code is unchanged. The change set is limited to documentation, release notes, a release-readiness source check, and reusable release-workflow note selection.

**Tech Stack:** Markdown, Bash, GitHub Actions, Gradle Android release workflow.

## Global Constraints
- Do not change VNC, SSH, SFTP, audio, Watch Mode, database, or credential behavior.
- Do not commit signing material or credentials.
- Release tag is `v1.0.0-rc1`.
- Signed APK remains produced by `.github/workflows/release.yml`.
